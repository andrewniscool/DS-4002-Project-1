# DS-4002-Project-1

This repository contains Project 1 for Group 4 in DS 4002.
## Section 1: Software and platform section 




RStudio was one of the software environments used for conducting the statistical analysis in this project. R was used to perform the hypothesis tests and assess the correlation between the variables of interest. The `ggplot2` and `dplyr` packages were used for data visualization and data manipulation.The project was conducted on a Mac computer running macOS Ventura 13.2.1. The version of R used for the analysis was R 4.5.2, with RStudio serving as the development environment.
